You can use these credentials to authenticate the following nodes:

* [Brevo node](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.brevo)
* [Brevo Trigger node](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.brevotrigger)

## Prerequisites

Create a [Brevo](https://www.brevo.com/) developer account.

## Supported authentication methods

- API key

## Related resources

Refer to [Brevo's API documentation](https://developers.brevo.com/docs/api-key-authentication) for more information about authenticating with the service.

## API key

To configure this credential, you'll need:

- An **API Key**: Refer to the [Brevo API Quick Start documentation](https://developers.brevo.com/docs/getting-started#quick-start) for instructions on creating a new API key.
