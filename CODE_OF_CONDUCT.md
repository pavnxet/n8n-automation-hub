# Code of conduct

## Scope

This repository is public and single-maintainer. These rules apply to issues, pull requests,
commit messages and review comments.

## Expected behaviour

- Be direct about the work and generous about the person. Critique the workflow, not the author.
- Assume the reader is competent and busy. Say the thing, then the reason.
- Attribute what you did not write. A workflow copied from a blog is not yours to present as new.
- Respect licences. If a source says non-commercial, it does not enter a commercial context.
- Keep credentials and personal data out of the repository, always.

## Not acceptable

- Harassment, insults, or demeaning comments about a person or a group.
- Publishing someone else's private information.
- Presenting scraped material as original work, or stripping attribution to make it look so.
- Deliberately introducing code or workflows that exfiltrate data or harm the host.

## Enforcement

The maintainer may edit, close or revert any contribution that breaks these rules, and may
restrict access for repeat breaches. Concerns go to the maintainer directly.
